# Expected differences for identity_diff.py --tiers and classify_dryrun.py.
#
# One case per line: <case key> | <reason>
#               or:  <case key> | keys=<record key>,... | <reason>
#
# The key is a case key of operand_probe.py, fixture_snapshot.py or classify_dryrun.py,
# matched whole: * stands for any run of characters, \* for a star, \\ for a backslash.
# With keys=, the entry allows a first-tier difference in those record keys only.  The
# reason states the rule the new verdict follows.
#
# A case belongs here only when
#   (a) CLICK shows that the verdict before the change was wrong, or
#   (b) before the change, the field value made the code raise something other than a
#       FieldError or AddressError: a crash, not a verdict.
# A message-only change needs no entry: --tiers lists it apart.  An entry lives on the
# branch that adds it; the next branch that touches this file removes the entries the
# tools report as matching no difference.

# (b) More than 4300 digits: Python's int() refuses the text with a ValueError.  Leading
# zeros do not count, so '0'*5000+'1' is the integer 1, and '1'*5000 is out of range.
